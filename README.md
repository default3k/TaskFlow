# TaskFlow - система управления задачами

Django веб-приложение для управления компаниями, проектами и задачами с системой ролей (владелец, админ, менеджер, разработчик, дизайнер, тестировщик и соискатель).

## Требования

- Python 3.10 или выше (рекомендуется **Python 3.10, 3.11 или 3.12**)
- pip (менеджер пакетов Python)
- SQLite (встроен в Python, дополнительная установка не требуется)

## Установка и запуск

### 1. Клонирование репозитория

```
git clone <url-вашего-репозитория>
cd <название-папки-проекта>
```
2. Создание виртуального окружения
Windows:

```
python -m venv venv
venv\Scripts\activate
```
macOS / Linux:

```
python3 -m venv venv
source venv/bin/activate
```
3. Установка зависимостей
Создайте файл requirements.txt со следующим содержимым:

```
Django>=4.2,<5.1
```
Затем установите зависимости:

```
pip install -r requirements.txt
```
4. Применение миграций базы данных
```
python manage.py makemigrations
python manage.py migrate
```
5. Создание суперпользователя (администратора)
```
python manage.py createsuperuser
```
Следуйте инструкциям — укажите имя пользователя, email (опционально) и пароль.

6. Запуск сервера разработки
```
python manage.py runserver
```
